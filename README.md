# 🚀 Ajit Bedwal | Personal Portfolio Website

A modern, interactive, and fully responsive personal portfolio website designed to showcase my professional identity, technical expertise, educational background, projects, internship experience, achievements, and career journey.

Built using **HTML5, CSS3, and Vanilla JavaScript**, this portfolio combines a premium dark interface, modern UI/UX design, smooth animations, interactive components, and responsive layouts to create an engaging digital experience.

## 🌐 About the Project

This portfolio serves as my personal digital identity, highlighting my journey as a Computer Engineering student and aspiring AI and Software Developer.

The main objective is to present my technical skills, practical experience, development projects, and professional interests in an organized and visually appealing manner.

The website is designed to provide recruiters, developers, and potential collaborators with an overview of my background, capabilities, and work.

## ✨ Key Features

- **Modern Dark Theme:** Premium dark interface with elegant gradients, glowing effects, and glassmorphism-inspired components.
- **Interactive Hero Section:** Animated introduction, professional headline, and engaging call-to-action buttons.
- **About Me:** Personal introduction, professional summary, and career interests.
- **Education:** Academic background presented through an interactive timeline.
- **Technical Skills:** Organized display of programming languages, frameworks, tools, and technologies.
- **Project Showcase:** Interactive project cards with descriptions, technology stacks, GitHub links, and live demos where available.
- **Internship Experience:** Professional experience, responsibilities, and practical learning.
- **Achievements & Certifications:** Highlights of academic and professional accomplishments.
- **Career Goals:** Visual representation of professional aspirations and learning journey.
- **Hobbies & Interests:** A section showcasing personal interests beyond technology.
- **Resume Download:** Dedicated section to access my professional resume.
- **Contact Section:** Contact information and an interactive contact form.
- **Smooth Animations:** Scroll-triggered animations, hover effects, transitions, and dynamic visual elements.
- **Responsive Design:** Optimized layouts for mobile phones, tablets, laptops, and desktop screens.
- **Interactive Navigation:** Smooth scrolling and active section highlighting.

## 🚀 Getting Started

Follow these steps to run the portfolio locally.

**1. Clone the repository**

```bash
git clone https://github.com/YOUR-USERNAME/ajit-bedwal-portfolio.git
```

**2. Navigate to the project directory**

```bash
cd ajit-bedwal-portfolio
```

**3. Open the project**

Open `index.html` directly in your browser or use the Live Server extension in Visual Studio Code.
